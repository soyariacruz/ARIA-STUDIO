# ARIA STUDIO · versión web

La versión en línea de ARIA STUDIO: entrar con Google y crear imágenes y vídeos con tus propios personajes de IA.

- `public/` — lo que se publica en Vercel (la web).
- `web_dev.py` — servidor de desarrollo: `python3 web_dev.py` abre la web en `http://localhost:3000` hablando con el puente local (`puente.py`, puerto 8767).

Cuentas: Supabase (login con Google). En el código solo va la clave pública del proyecto; ninguna clave secreta se guarda aquí.
